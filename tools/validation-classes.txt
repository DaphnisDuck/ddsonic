# ddsonic: the validation classes of changed paths, read by
# tools/classify-change.sh (docs/ddsonic/acceptance.md, "Proportional
# validation"). Each line is a class and a pattern: docs, test, code or full,
# then a glob in which * matches any characters, / included. The first line
# whose pattern matches a path decides its class, so the strongest classes
# come first. A path that no line matches is full. A malformed line, or a
# class not among the four, makes the whole classification full.
#
# A change's class is the strongest of its paths' classes. Besides these
# lines, the classifier makes a change full for a symlink, a submodule, a
# mode or type change, a binary file, a deleted or renamed test, a path it
# cannot read safely, an empty diff, and any error.
